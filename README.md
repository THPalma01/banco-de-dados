# 🗄️ Exercícios de Banco de Dados

## 🧠 Descrição

Repositório contendo exercícios resolvidos envolvendo manipulação, criação e consulta de dados usando python e sqlite3.

## 🎯 Objetivo

Praticar conceitos fundamentais de banco de dados.

## 🛠️ Tecnologias

* SQL

## 📚 Conteúdo

* Consultas básicas (SELECT)
* Filtros e condições
* Manipulação de dados
* Estruturação de tabelas

## 🧠 Conceitos aplicados

* Modelagem de dados
* Consulta estruturada
* Organização de informações

## ▶️ Como executar

Executar os scripts em SqLite3.
